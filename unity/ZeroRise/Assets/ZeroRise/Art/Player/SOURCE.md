Base geometry and default streetwear exported from our dist/citizen.js and dist/clothing.js using the bundled Three.js. Unity adds smooth surface refinement, facial/clothing detail, HDRP fabric materials, a generic skinning rig and authored locomotion/jump/landing clips. No external character, motion-capture pack or downloaded model is used. Re-export with node tools/export-unity-player.mjs after intentionally updating the browser base.
